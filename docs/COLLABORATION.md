# 两人云端协作

## 默认编辑方式

优先使用本地 Codex 客户端连接 `Anzu327/6311ass2` 的云端工作区。客户端在电脑上操作，项目文件、命令和预览都在云端执行；不要在电脑上克隆或编辑本地副本。

仓库拥有者邀请搭档作为 Collaborator，搭档使用自己的 GitHub 账号接受邀请，在 Codex 中授权仓库并选择绑定本项目的云端环境。让 GPT 检查实际工作目录、远程仓库、分支和已有修改。具体入口以客户端版本为准；无法连接时说明缺少的设置，可用 Codespaces 作为云端备选。

详细设置及可复制给 GPT 的指令见 [设计与 Codex 交接](DESIGN_AND_CODEX_HANDOFF.md)。GitHub 连接器授权不代表终端 Git 自动登录；GitHub Actions 负责检查和发布，不负责开启编辑权限。

## 每轮同步

1. 两人都可以按需求编辑内容、界面、交互和特效，不设固定分工。
2. 开始前同步最新 `main`，保护已有修改，不直接覆盖或丢弃。
3. GPT 在云端完成修改和相应检查；涉及界面时自己启动服务器并打开预览。
4. **每次编辑完成、检查无误后，GPT 主动提交并推送到远程 `main`，不必等再次提醒。** 不以功能分支或未合并 PR 作为最终交付。
5. 推送前检查远程是否新增提交；整合搭档的修改，解决冲突后重新检查，再正常推送，不强制覆盖。
6. 读回远程确认更新，报告检查结果、`main` 同步状态及真实提交链接。权限、网络或分支保护阻止更新时说明实际原因；不能把仅保存或仅 commit 当作同步成功。

`src/content.ts` 存放推荐内容：保持三个身份和每个身份六条帖子，第四条为虚构广告，最后两条表现推荐收窄。代码修改运行 `npm run typecheck`、`npm test`、`npm run build` 和 `npm run test:sites`；纯文档修改检查内容、链接与 diff。自动检查不能代替真实摄像头与移动端体验验证。

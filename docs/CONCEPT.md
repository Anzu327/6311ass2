# WIP：FOR YOU

## 观察平台
TikTok / Douyin。以竖屏推荐流、面部滤镜、身份包装及个性化推荐为观察对象。作品借用界面语法，不复制官方品牌。

## 网络美学
Glitch。前期界面清晰可信，后期文字重复、颜色错位、画面被标签覆盖。故障不是装饰，而是平台对复杂个体进行僵硬分类的可见表现。

## 批判概念
平台是在理解我们，还是在塑造我们？作品把算法画像夸张为「观众表达兴趣之前，平台先替观众决定身份」。脸的位置被真实检测，但身份随机赋予，因此所谓分析精度没有真实性依据。推荐逐渐同质化，第四条把身份转化成消费诉求。观众否认标签，平台礼貌回应，却不改变推荐。

「个人个性完全不能影响平台」不是本作品要证明的事实；这里用故意不响应的虚构系统，讨论被定义与选择权之间的张力。

## 最终形式
可在手机和电脑浏览器体验的交互数字艺术作品。真实摄像头或虚构肖像进入，扫描、定性、随脸移动特效、六条推荐、重置失败、解释与重启形成完整叙事。没有登录、真实社交发布、个人档案或云端人脸存储。

## 展示顺序
1. 进入：用户被邀请让平台「认识」自己。
2. 定性：WE KNOW YOU；点击否认。
3. 推荐：刷至第五、六条，观察标签覆盖。
4. 重置：Same result；讨论平台理解与塑造的区别。
